# Delegation guidance

Use delegation for substantial independent work when it improves speed, context
use, or verification. Keep trivial and tightly sequential work in the main agent.
Follow the current session's tool and model constraints.

The main agent owns task scope, architecture, integration, conflict resolution,
and final verification. Useful delegated tasks include bounded exploration,
independent debugging hypotheses, non-overlapping implementation, and review.

- Give each agent one objective, explicit file ownership, and a clear deliverable.
- Choose an economical capable model when model selection is available and allowed.
- Run independent tasks in parallel; avoid overlapping edits and competing benchmarks.
- Request concise findings with paths, symbols, evidence, commands, and uncertainties.
- Wait for dependent findings, assess them critically, and verify the integrated result.
- Avoid recursive delegation unless the child task has substantial independent parts.

Use cross-model delegation only when available and useful; read its applicable
skill before use. The main agent retains responsibility for the result.
