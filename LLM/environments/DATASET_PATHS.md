Depending on the place where the script is supposed to be executed, two different paths for datasets are available:

CERES:
There is a folder called Datasets in: ~/Datasets

There you have:
    - Imagenette (~/Datasets/imagenette2)
    - MNIST (~/Datasets/MNIST)
    - cifar 100 (~/Datasets/cifar-100-python/)
    - SVHN (~/Datasets/SVHN)
    - Animals with Attributes 2 (~/Datasets/Animals_with_Attributes2)
    - CUB (~/Datasets/CUB_200_2011)

You also have the keel_datasets folder there.

Burrita:
(Remember, this is the local desktop)
There is a folder called Datasets in: home/javier/Documentos/Datasets

There you have:
    - CUB (home/javier/Documentos/Datasets/CUB_200_2011)
    - FashionMNIST
    - MNIST
    - PCAM (home/javier/Documentos/Datasets/pcam)
    - SVHN
    - Animals with Attributes 2 (/home/javier/Descargas/AwA2-data/Animals_with_Attributes2)
      NOTE: currently under ~/Descargas, not the canonical Datasets folder.

Keel datasets are in burrita, however, whithin the home/javier/Documentos/keel_datasets/ folder.

If at any point you need to download any dataset:
    1. Do it in the correspondent Dataset folder, depending on where you are being run.
    2. Update this document to properly reflect the dataset is now available and where.
